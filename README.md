**简单看个片。** 面向遥控器的 Android TV 播放器，专注自定义端口 SMB，以及用户指定的本地 / USB 文件夹。

[English](docs/README.en.md) · [构建与 CI](#构建) · [参与开发](CONTRIBUTING.md) · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/andrewdickies/smbplayer/issues)

用于本地、USB 和 SMB 视频的 Android TV 播放器。深色大字界面，遥控器优先。最低 Android 6.0，仅打包 **armeabi-v7a（32 位 ARM）**；支持该 ABI 的 64 位设备同样可运行。播放引擎 LibVLC 3.6.5。

## 安装

从 [GitHub Actions](https://github.com/andrewdickies/smbplayer/actions/workflows/android.yml) 最近成功运行的 Artifacts 下载 `smbplayer-armeabi-v7a-debug`，解压 APK 后安装；或按下文自行构建。Artifacts 需要登录 GitHub，保留 30 天。源码仓库不存放历史 APK。

当前版本为 **0.29**。CI 产物是测试构建，签名可能随构建环境变化，不能保证覆盖开发者本机的已安装版本。正式分发时请使用自己的固定签名密钥，并在后续版本沿用；不要把密钥提交到仓库。应用会保留同签名覆盖更新时的服务器、加密密码和续播记录。

本项目只打包 32 位 ARM；支持 armeabi-v7a 的 64 位设备也可运行，**纯 64 位系统无法安装**。不支持 x86 模拟器。

## 主页与来源

首页仅保留居中的「本地存储」「SMB 网络」两个卡片，设置位于右上角。宽度不足时上下排列；按上进入设置，按下回到卡片，返回恢复入口焦点。

确认卡片后进入来源列表。模块左上角是返回和标题，右上角是添加或排序、视图；路径单独一行。

- 本地存储支持多个用户选择的文件夹，包含内置存储和 USB。打开哪个才读取哪个，不全盘扫描。长按移除入口，不删除真实文件。旧版已选文件夹自动迁入。
- SMB 支持多个服务器、自定义端口和子目录，密码加密保存在设备上。添加 / 编辑表单只在相应操作时出现。
- 已移除 M3U/M3U8 导入与网络串流模块；升级会清理这两类已保存来源，本地及 SMB 来源保留。
- 网络来源长按 OK 或菜单键管理：编辑、复制为新来源、删除。列表只显示来源名称。

## 文件浏览

默认列表，可切换网格并记住选择。显示文件名、可读取的时长、修改时间、文件大小和静态缩略图，不展示联网影片资料。文件夹使用矢量图标，名称不带末尾斜杠。

右上角「排序」直接选择名称、修改时间、文件大小的正序 / 倒序，或随机。文件夹始终在前；随机使用稳定种子，返回和切换视图不会自行重排。「视图」选择列表 / 网格。返回目录保留选中项目，列表尽量恢复原滚动位置。

小于 1 MB 显示 kB，否则显示 MB；按 1024 字节换算，kB 向上取整，MB 一位小数，不切换到 GB。缺失信息标记未知。SMB 缩略图每项最多读取 2 MiB、限时约 5 秒，后台单线程且有界；播放时取消预览，把连接和带宽留给视频。

## 播放操作

底栏只有 **播放 / 暂停、选集、比例、倍速、更多**，进度条单独一行，顶部是返回和影片名。

| 操作 | 行为 |
| --- | --- |
| 隐藏时确认 | 播放 / 暂停，不显示两栏 |
| 隐藏时左右 | 快退 / 快进及短暂提示；长按逐级加速到 1、5、10 分钟 |
| 隐藏时上 | 显示两栏，焦点落在播放 / 暂停 |
| 隐藏时下 | 打开选集 |
| 点击视频画面 | 同时显示或隐藏两栏，不改变播放状态 |
| 两栏显示时返回 | 收起两栏 |
| 两栏隐藏时返回 | 提示再次按返回退出；2.4 秒内再次按下回目录 |
| 顶部返回 | 直接回原目录 |
| 触摸进度条 | 点击 / 拖动定位，保留原播放或暂停状态 |

两栏同步显隐；播放时约 4 秒无操作隐藏。选集、更多打开和关闭后保持两栏隐藏。浮层内返回只关闭浮层。媒体键和系统音量键可直接使用，熄屏自动暂停。

- 选集只显示名称和可读取的时长，沿用目录排序，正在播放的条目标记高亮。顶部只有循环模式按钮：顺序播放、单集循环、列表循环。当前队列的临时循环模式在换集时保留，离开播放后恢复主页默认。
- 比例：适应、填充、拉伸、16:9、4:3。
- 倍速：0.75×、1×、1.5×、2×、2.5×、3×。
- 更多只有字幕、音轨、旋转 / 翻转、定时停止。
- 字幕支持选择 / 关闭、同目录自动匹配 SRT/ASS/VTT、手动加载、三档字号和时间偏移；音轨支持选择及音频偏移。
- 定时停止：关闭、15、30、60、90 分钟，只停止本应用播放。
- 滑块即时生效，没有取消 / 应用。旋转、翻转、字幕大小仍需重建 LibVLC，保留位置、暂停、倍速、音轨与已加载外挂字幕。

## 设置范围

主页设置一页六项：续播方式、快进步长、默认字幕大小、播放结束、兼容性设置、关于。兼容性仅有自动 / 软件解码、音频透传自动 / 关闭 / 开启、SMB 缓存 / 原生 / 串行兼容。

新视频从 1×、适应屏幕、原始方向和零音画偏移开始，字幕大小继承全局默认。播放页调整只影响当前视频，同片重建保留，换片或退出清除；没有「保存为全局默认」。

自动透传保守依据 HDMI/ARC/eARC 压缩格式和系统当前直通能力判断；连接音频设备时重新评估。旧系统缺少路由能力查询时，检测到其他外接音频设备则不自动透传。真实电视、功放和系统支持仍决定 HDR、音频透传和 CEC 表现；K30 不代替这些硬件验收。

## 播放与缓存

SMB 缓存通道使用 8 工作者独立向前下载，磁盘缓存最高 1 GiB，按文件大小与剩余空间收缩。可解析索引的视频以连续可播 60 秒为目标，低于 30 秒恢复填充；其他格式按平均码率估算字节目标，不保证准确缓存时长。暂停时仍可继续预缓存，跳转会取消过时预读，前台读取优先并共享已下载数据；失败保留串行回退。LibVLC 输入缓冲为 3500ms，独立于磁盘缓存。

持续监测声音 / 时钟前进而画面停滞，包括没有缓冲事件的情况。跳转、暂停后继续及断流恢复期间暂时抑制音频，按实际出帧恢复；必要时重同步或重建解码器，保留位置和轨道。仅显示“正在缓冲”及网速，不显示恢复阶段提示，不自动唤出两栏。部分电视不报告显示帧计数，此时只能参考解码计数，实际电视恢复效果仍需实机验证。见 `VALIDATION.md`。

本版删除章节、AB、第二字幕、联网海报 / 简介、画中画、快捷键自定义、精细色彩 / 降噪 / 锐化 / 去交错、缩放平移、均衡器和增益的专用实现。保留引擎自动解码回退、正常 HDR 输出、系统媒体键及上述核心播放功能。

## 构建

需要 JDK 17、Android SDK Platform 35 / Build Tools 35.0.0；仓库自带 Gradle 8.10.2 Wrapper。设置 `JAVA_HOME` 和 `ANDROID_HOME`，或用 Android Studio 打开项目并配置 SDK。首次构建需要下载公开依赖。

```sh
git clone https://github.com/andrewdickies/smbplayer.git
cd smbplayer
./gradlew :app:assembleDebug :app:lintDebug
python3 scripts/check.py
```

Windows 使用 `gradlew.bat`、`python`。输出位于 `app/build/outputs/apk/debug/app-debug.apk`。

CI 自动执行 9 组无网络主机检查、Android 构建、lint 及 APK ABI / 测试隔离检查，并保存 APK 与 lint 报告。设备、真实 SMB 和媒体样本测试为可选手工检查，见 [checks/README.md](checks/README.md)。验证历史与硬件限制见 [VALIDATION.md](VALIDATION.md)。

## 项目结构

```text
app/src/main/       Android 界面、播放和 SMB 缓存实现
checks/             主机检查、可选设备 / 网络测试工具
scripts/            跨平台检查入口及 APK 验证
docs/               英文说明与架构文档
.github/            自动构建、问题和 PR 模板
```

[架构说明](docs/ARCHITECTURE.md)介绍 LibVLC、回环 HTTP 数据桥、前向缓存与冻帧恢复的关系。应用没有自建账号、广告或遥测服务；不会自动全盘扫描视频。
