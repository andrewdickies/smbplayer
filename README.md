**简单看个片。** 面向遥控器的 Android TV 播放器，专注自定义端口 SMB，以及用户指定的本地 / USB 文件夹。

[English](docs/README.en.md) · [构建与 CI](#构建) · [参与开发](CONTRIBUTING.md) · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/andrewdickies/smbplayer/issues)

用于本地、USB 和 SMB 视频的 Android TV 播放器。深色大字界面，遥控器优先。最低 Android 6.0，仅打包 **armeabi-v7a（32 位 ARM）**；支持该 ABI 的 64 位设备同样可运行。播放引擎 LibVLC 3.6.5。

## 安装

从 [GitHub Actions](https://github.com/andrewdickies/smbplayer/actions/workflows/android.yml) 最近成功运行的 Artifacts 下载 `smbplayer-armeabi-v7a-debug`，解压 APK 后安装；或按下文自行构建。Artifacts 需要登录 GitHub，保留 30 天。源码仓库不存放历史 APK。

当前版本为 **1.2.3**。CI 产物是测试构建，签名可能随构建环境变化，不能保证覆盖开发者本机的已安装版本。正式分发时请使用自己的固定签名密钥，并在后续版本沿用；不要把密钥提交到仓库。应用会保留同签名覆盖更新时的服务器、加密密码和续播记录。

本项目只打包 32 位 ARM；支持 armeabi-v7a 的 64 位设备也可运行，**纯 64 位系统无法安装**。不支持 x86 模拟器。

## 主页与来源

首页仅保留居中的「本地存储」「SMB 网络」两个卡片，设置位于右上角。宽度不足时上下排列；按上进入设置，按下回到卡片，返回恢复入口焦点。

确认卡片后进入来源列表。模块左上角是返回和标题，右上角是添加或筛选、排序、视图，锁图标固定在最右。文件夹路径单独显示。

- 本地存储支持多个用户选择的文件夹，包含内置存储和 USB。打开哪个才读取哪个，不全盘扫描。长按移除入口，不删除真实文件。旧版已选文件夹自动迁入。
- SMB 支持多个服务器、自定义端口和子目录，密码加密保存在设备上。添加 / 编辑表单只在相应操作时出现。
- 已移除 M3U/M3U8 导入与网络串流模块；升级会清理这两类已保存来源，本地及 SMB 来源保留。
- 网络来源长按 OK 或菜单键管理：编辑、复制为新来源、删除。列表只显示来源名称。

## 文件浏览

默认列表，可切换网格并记住选择。列表显示文件名、可读取的时长、修改时间、文件大小和静态缩略图，网格只显示缩略图与一行文件名，不展示联网影片资料。文件夹使用矢量图标，名称不带末尾斜杠。

右上角「排序」直接选择名称、修改时间、文件大小的正序 / 倒序，或随机。文件夹始终在前；随机使用稳定种子，返回和切换视图不会自行重排。「视图」选择列表 / 网格。返回目录保留选中项目，列表尽量恢复原滚动位置。

小于 1 MB 显示 kB，否则显示 MB；按 1024 字节换算，kB 向上取整，MB 一位小数，不切换到 GB。缺失信息标记未知。SMB 缩略图每项最多读取 2 MiB、限时约 5 秒，后台单线程且有界；播放时取消预览，把连接和带宽留给视频。

缓存启动时预留至少 1 GiB 或剩余空间的 15%（取较大值），预算不足时缩小缓存。缓存文件随写入增长，不预分配整个预算；已播放部分在容量内保留，用满时优先淘汰保护窗口之外较旧且距离较远的片段。退回已淘汰的位置需要重新联网读取。

## 图片、音乐与隐私

- 目录默认显示全部媒体。右上角可筛选视频、图片或音乐，列表 / 网格按钮每按一次切换视图，对所有筛选均有效。图片全屏浏览，顶部显示返回图标及当前文件名，与底部工具栏同步显隐。底部工具栏提供照片列表、缩放、适应 / 充满和幻灯片设置。方向键翻页或平移，触摸支持滑动、双击与捏合。幻灯片用 OK 暂停 / 继续，停留时间可设为 3、5、10、15 或 30 秒。
- 音乐支持 FLAC、APE、MP3、AAC / M4A、WAV、OGG 等。播放队列只包含当前目录的可见歌曲。有同名 LRC 时显示同步歌词，打开队列会暂时替换右侧歌词。遥控器在底栏移动焦点，选中上一首或下一首后按 OK 切歌。图片、音乐回目录均需连续按两次返回，打开的面板会优先关闭。
- 音乐播放时约 4 秒无操作会收起透明上下栏，左侧圆形封面随播放缓慢旋转，右侧歌词可滑动浏览。控制栏隐藏时封面与歌词扩展，显示时整体平滑上移。按上键显示控制栏并聚焦播放键，按下键打开右侧浮动队列。控制栏隐藏时，左右键快退 / 快进并短暂显示进度。
- 普通看图与幻灯片共用临时缓存，提前读取前后各 5 张，缓存内的照片可直接回看。幻灯片随机使用淡入淡出、缓慢推进或拉远；横图铺满屏幕，相邻竖图并排显示，单独的竖图配模糊背景。
- 本地和 SMB 模块的锁图标打开隐私列表，共用六位 PIN。长按文件、目录或来源可隐藏。退到后台、熄屏或离开隐私列表会重新上锁。隐私功能管理本应用中的显示，文件访问权限由系统或 SMB 服务器管理。
- 解锁隐私列表后，右上角的 PIN 设置可以修改或清除 PIN。两项操作都需要验证当前 PIN。确认清除后，本地和 SMB 的隐私项目会恢复到普通列表。
- PIN 输入满六位自动提交。
- 图片在填充屏幕时可用遥控器左右翻页，手动放大时方向键平移。返回先恢复适应屏幕，再连续按两次回目录。
- 长按文件或目录可重命名、删除。删除需确认，目录删除需二次确认。若本地来源是旧版只读授权，请通过系统文件夹选择器重新授权写入。
- 视频触摸新增双击两侧快进 / 快退，以及横向拖动画面预览位置后松手跳转。

音乐可在回到目录、切换应用和熄屏后继续播放。通知栏提供播放 / 暂停、上一首、下一首和停止，点击通知返回当前歌曲。音乐底栏在播放 / 暂停旁提供停止按钮。停止后保留封面、歌词和列表，进度归零，释放播放资源并结束后台服务，再次播放从头开始。首页播放图标可返回正在播放的音乐。打开视频时停止背景音乐。

支持画中画的设备上，视频按 Home 或点击底栏「更多」前的画中画图标进入系统小窗，返回应用恢复完整播放界面。画中画依赖 Android 8.0 及以上和设备支持。

## 播放操作

底栏为 **播放 / 暂停、选集、比例、倍速、画中画、更多**，画中画入口按设备支持显示，进度条单独一行，顶部是返回和影片名。

| 操作 | 行为 |
| --- | --- |
| 隐藏时确认 | 播放 / 暂停，不显示两栏 |
| 隐藏时左右 | 仅显示共享进度条、目标时间及累计跳转量，停止操作约 2 秒后收起，缓冲时保留；长按逐级加速到 1、5、10 分钟 |
| 隐藏时上 | 显示两栏，焦点落在播放 / 暂停 |
| 隐藏时下 | 打开选集 |
| 点击视频画面 | 同时显示或隐藏两栏，不改变播放状态 |
| 两栏显示时返回 | 收起两栏 |
| 两栏隐藏时返回 | 提示再次按返回退出；2.4 秒内再次按下回目录 |
| 顶部返回 | 直接回原目录 |
| 触摸进度条 | 点击 / 拖动定位，保留原播放或暂停状态 |

两栏同步显隐；视频和图片播放时约 4 秒无操作隐藏，按键、触摸和拖动期间重新计时。选集、更多打开和关闭后保持两栏隐藏。浮层内返回只关闭浮层。媒体键和系统音量键可直接使用，熄屏自动暂停。

- 选集只显示名称和可读取的时长，沿用目录排序，正在播放的条目标记高亮。顶部只有循环模式按钮：顺序播放、单集循环、列表循环。当前队列的临时循环模式在换集时保留，离开播放后恢复主页默认。
- 比例：适应、填充、拉伸、16:9、4:3。
- 倍速：0.75×、1×、1.5×、2×、2.5×、3×。
- 更多只有字幕、音轨、旋转 / 翻转、定时停止。
- 字幕支持选择 / 关闭、同目录自动匹配 SRT/ASS/VTT、手动加载、三档字号和时间偏移；音轨支持选择及音频偏移。
- 定时停止：关闭、15、30、60、90 分钟，只停止本应用播放。
- 滑块即时生效，没有取消 / 应用。旋转、翻转、字幕大小仍需重建 LibVLC，保留位置、暂停、倍速、音轨与已加载外挂字幕。

## 设置范围

主页设置一页六项：续播方式、快进步长、默认字幕大小、播放结束、兼容性设置、关于。兼容性仅有自动 / 软件解码、音频透传自动 / 关闭 / 开启、SMB 缓存 / 原生 / 串行兼容。

新视频从 1×、适应屏幕、原始方向和零音画偏移开始，字幕大小继承全局默认。播放页调整只影响当前视频，同片重建保留，换片或退出清除；没有「保存为全局默认」。

自动透传保守依据 HDMI/ARC/eARC 压缩格式和系统当前直通能力判断；连接音频设备时重新评估。旧系统缺少路由能力查询时，检测到其他外接音频设备则不自动透传。真实电视、功放和系统支持仍决定 HDR、音频透传和 CEC 表现；K30 不代替这些硬件验收。

## 播放与缓存

SMB 缓存通道使用 8 工作者独立向前下载，磁盘缓存最高 5 GiB，按文件大小与剩余空间收缩。可解析索引的视频以连续可播 5 分钟为目标，低于 4 分钟恢复填充；其他格式按平均码率估算字节目标，不保证准确缓存时长。暂停时仍可继续预缓存，跳转会取消过时预读，前台读取优先并共享已下载数据；失败保留串行回退。LibVLC 输入缓冲为 3500ms，独立于磁盘缓存。

持续监测声音 / 时钟前进而画面停滞，包括没有缓冲事件的情况。跳转、暂停后继续及断流恢复期间暂时抑制音频，按实际出帧恢复；必要时重同步或重建解码器，保留位置和轨道。缓冲时在透明浮层显示网速。部分电视不报告显示帧计数，此时只能参考解码计数，实际电视恢复效果仍需实机验证。见 `VALIDATION.md`。

本版删除章节、AB、第二字幕、联网海报 / 简介、画中画、快捷键自定义、精细色彩 / 降噪 / 锐化 / 去交错、缩放平移、均衡器和增益的专用实现。保留引擎自动解码回退、正常 HDR 输出、系统媒体键及上述核心播放功能。

## 构建

需要 JDK 17、Android SDK Platform 35 / Build Tools 35.0.0；仓库自带 Gradle 8.10.2 Wrapper。设置 `JAVA_HOME` 和 `ANDROID_HOME`，或用 Android Studio 打开项目并配置 SDK。首次构建需要下载公开依赖。

```sh
git clone https://github.com/andrewdickies/smbplayer.git
cd smbplayer
./gradlew :app:assembleDebug :app:lintDebug
python3 scripts/check.py
```

Windows 使用 `gradlew.bat`、`python`。输出位于 `app/build/outputs/apk/debug/app-debug.apk`。

压缩构建：`./gradlew :app:assembleRelease :app:lintRelease`，输出 `app/build/outputs/apk/release/app-release.apk`。启用 R8 与无用资源裁剪；保守保留 LibVLC JNI、SMB 和加密相关类，不修改原生库。当前仍使用构建机器的开发签名，以便本机覆盖测试，并非生产私钥签名。CI 提供 `smbplayer-armeabi-v7a-optimized` 产物及反混淆 mapping；不同机器的签名不保证一致。正式分发请替换为自己的固定签名配置，保管每次发布对应的 mapping 文件。

CI 自动执行 10 组无网络主机检查、Android 构建、lint 及 APK ABI / 测试隔离检查，并保存 APK 与 lint 报告。设备、真实 SMB 和媒体样本测试为可选手工检查，见 [checks/README.md](checks/README.md)。验证历史与硬件限制见 [VALIDATION.md](VALIDATION.md)。

## 项目结构

```text
app/src/main/       Android 界面、播放和 SMB 缓存实现
checks/             主机检查、可选设备 / 网络测试工具
scripts/            跨平台检查入口及 APK 验证
docs/               英文说明与架构文档
.github/            自动构建、问题和 PR 模板
```

[架构说明](docs/ARCHITECTURE.md)介绍 LibVLC、回环 HTTP 数据桥、前向缓存与冻帧恢复的关系。应用没有自建账号、广告或遥测服务；不会自动全盘扫描视频。
